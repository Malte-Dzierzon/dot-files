# Ghostty

Default terminal. Palette comes from Noctalia, not from here.

Target: `~/.config/ghostty/` = `config` + `themes/noctalia` + `shaders/` (all versioned here).

## Files here

| File | What |
|---|---|
| `config` | Maple Mono 14 + JetBrainsMono NFM fallback, padding 10, opacity 0.9, scrollback 10000, blinking block cursor, one cursor shader. No colors — `theme = noctalia`. |
| `themes/noctalia` | Generated by Noctalia (template `ghostty`). Reference copy; live version is rewritten via `noctalia msg templates-apply`. |
| `shaders/` | Cursor shaders, vendored from [ghostty-cursor-shaders](https://github.com/sahaj-b/ghostty-cursor-shaders). Active: `cursor_trail_kitty_physics.glsl`. |

## Install

```bash
cp -r Config/ghostty ~/.config/ghostty
```

Then per machine:

1. Fix the shader path — `config` uses an absolute `custom-shader` path. Point it at your home directory.
2. Fonts: Maple Mono + JetBrainsMono Nerd Font in `~/.local/share/fonts`, then `fc-cache -r`.
3. Noctalia template: `theme.templates.builtin_ids` in `~/.local/state/noctalia/settings.toml` must contain `"ghostty"`, then `noctalia msg templates-apply`.
4. Set as default: `default-app --set terminal ghostty`.
5. Check: `ghostty +validate-config` must be silent, then reload Ghostty.
